# AIOS 체험(UAT) 사용 안내

> 모의(PAPER) 전용 체험 스택입니다. 실제 자금·실계정과 연결되지 않습니다. 이 문서는 **지금 실제로 되는 것과 안 되는 것**을 있는 그대로 적습니다(2026-11-19 실스택 점검 기준).

## 1. 접속

- 웹: http://127.0.0.1:18080  (API: http://127.0.0.1:18000)
- 켜는 법: 저장소 루트에서 `python scripts/uat/up.py up` (끄기 `down`, 초기화 `reset`)
- 휴대폰에서: PowerShell에서 아래 두 줄을 실행한 뒤 `http://<이 PC의 Tailscale 주소>:18080`으로 접속합니다.
  ```powershell
  tailscale serve --bg --tcp 18080 tcp://127.0.0.1:18080
  tailscale serve --bg --tcp 18000 tcp://127.0.0.1:18000
  ```
- 로그인 계정: 저장소 루트의 `.env.uat` 파일에 있는 `UAT_DEMO_EMAIL` / `UAT_DEMO_PASSWORD`. (파일은 로컬 전용이며 Git에 올라가지 않습니다.)

## 2. 첫 로그인에서 일어나는 일 (미리 준비하세요)

1. 로그인하면 **2단계 인증(MFA) 설정이 필수**로 나옵니다. **Google Authenticator 같은 인증 앱이 필요**합니다(QR 스캔 또는 화면의 문자열 입력).
2. 이어서 **투자 성향 평가** 질문에 답합니다.
3. 그다음 "시작하기"(첫 실행 체크리스트)나 대시보드로 이동합니다.

> 주의: 이 데모 계정으로 MFA를 설정하면 이후 로그인마다 인증 앱의 6자리 코드가 필요합니다. 자동 테스트는 이 계정을 쓰지 않고 임시 계정을 만들어 씁니다.

## 3. 지금 실제로 되는 것

- 가입·로그인·MFA·투자 성향 평가 전 과정, 잘못된 비밀번호나 코드의 오류 표시.
- 스크립트 편집기(`/scripts/editor`)에서 스크립트 **컴파일**(서버의 실제 컴파일러). 문법 오류는 줄·열 위치와 함께 표시됩니다.
- 대시보드·포트폴리오·실행 제어판·위임장·거래소 연동·알림 등 화면이 **실제 서버 데이터**(지금은 비어 있음)로 열립니다.
- "데모 모드"(`/onboarding/demo`): 서버 키 없이 도는 오프라인 시뮬레이션입니다. 화면에서 실제 계좌가 아님을 확인하세요.

## 4. 지금 막혀 있는 것 (알려진 제약)

| 하려는 일 | 상태 | 이유 |
|---|---|---|
| 차트·스크리너·백테스트 | **빈 화면** | UAT에 시장 데이터(종목·캔들)가 아직 없습니다. 시드 도구를 만드는 중입니다(UA-11). |
| 스크립트 → "백테스트 실행" | 종목 지정 필요 안내만 나옴 | 위와 같은 이유 |
| 모의 주문(실행 생성) | **서버가 거부(404)** | 모의 주문도 거래소 자격증명이 필요합니다. 가짜 키는 서버가 거부합니다. 본인 Bitget 데모 키가 있다면 `.env.uat`의 `UAT_BITGET_DEMO_API_KEY` 등에 넣고 시드를 다시 돌리면 등록됩니다. 화면은 "요청한 항목을 찾을 수 없습니다"만 보여 줍니다(UA-5). |
| 모든 주문 | 위임장 없으면 차단 | `/mandates`에서 위임장을 먼저 만들어야 합니다. 이 안내가 첫 흐름에 없습니다(UA-6). |
| 팔로우·신호 소스·AI 스튜디오·What-if·세션 관리 | 화면은 있으나 **서버 기능이 없음** | 프런트가 부르는 API가 백엔드에 없습니다(배선 점검 결과, `docs/frontend/WIRING_FINDINGS_2026-11-19.md`). |

## 5. 써 보면서 이상한 점을 발견하면

- 무엇을 눌렀고 무엇이 보였는지(가능하면 화면 캡처)만 알려 주세요. 제가 `docs/frontend/UNSPECIFIED_ACTIONS.md`에 기록하고 명세를 먼저 고친 뒤 구현합니다.
- 서버가 오류를 돌려줬다면 화면에 보이는 **지원코드**(긴 ID)를 같이 알려 주시면 서버 기록과 바로 대조할 수 있습니다.

## 6. 현재 알려진 화면 결함 목록 (등록됨)

`docs/frontend/UNSPECIFIED_ACTIONS.md`의 UA-1 ~ UA-12 참고. 요약: 오류 문구가 스크린리더에 전달되지 않음(role=alert 아님), 컴파일 오류의 설명 문구 소실, 서버 거부 사유가 일반 문구로 바뀜, 메뉴 번역 키 노출(수정 중), 첫 로그인이 MFA로 유도됨을 사전에 알리지 않음.
