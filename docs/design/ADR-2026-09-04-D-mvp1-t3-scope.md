# ADR-2026-09-04-D: 1차 MVP = 최소 T3(프로 퀀트 프레임워크) 수준 — 범위 절단과 종료 기준

## Status
Accepted (2026-09-04, Chief Architect). 사용자 지시 "1차 MVP는 최소 T3 수준으로 만들어".
**Amended 2026-09-04 (같은 날, 사용자 지시 "1차 MVP에 post-MVP까지 붙여라. 실자금 개통은 1차 MVP 후")**: 아래 표의 "제외(post-MVP)" 열은
**전부 MVP-1에 포함**된다. 유일한 제외는 (a) L04·L05·L09·L11(DSL이 대체), (b) L4-30(Bitget 데모 키 확보 후), (c) 실자금(LIVE) 개통이다.
MVP-1 총 리프 = 208(미착수 204 + 진행 7 − 대체 4 + F-04 1). 순서는 그대로이되 post-MVP였던 리프는 같은 축의 뒤에 이어 붙인다:
MP·SIG는 맨 마지막. LIVE 개통은 MVP-1 종료 기준 10항 통과 후 별도 ADR(하드 가드 ADR-2026-08-29-E 해제는 Guard P2 대상 — 사람이 meta PR을 승인)로만 연다.

## Context
동종 등급표(T1 기관 OMS/EMS ~ T5 개인 스크립트)에서 T3는 NautilusTrader·LEAN·Freqtrade급 —
**실행 엔진·현실적 백테스트·전략 언어·지표 라이브러리가 프로 퀀트가 실사용할 수준**이다. AIOS는 통제 골격(T2 지향)은
갖췄으나 T3의 기준인 "백테스트=라이브 패리티, 현실적 체결 모델, 표현력 있는 전략 언어, 넓은 지표"가 비어 있다.
2026-09-04 기준 7개 L4 명세의 리프 326개 중 완료 115, 진행 7, 미착수 204.

## T3 종료 기준 (전부 자동 테스트·CI 증빙, 하나라도 없으면 MVP-1 미완)
1. **패리티**: 같은 AIOS Script·같은 데이터로 백테스트와 PAPER 실행이 동일한 신호·체결 로그를 낸다(I-05, 재현 키 동일).
2. **안전 배선 증명**: kill switch ACTIVE·DataDistrust DEGRADED 상태에서 실행 루프의 제출이 항상 거부되는 적대적 테스트(I-01), 인스턴스 2개 동시 기동 시 중복 tick 0건(I-02), 게이트 파라미터 Optional 0건 정적 검사.
3. **검증 게이트 실효**: 임계 미달 전략이 실제로 FAIL(I-07), DSR/PBO/워크포워드가 코드로 계산되어 마켓 승인 경로가 이를 조회.
4. **전략 언어**: DSL 문법·타입·미래참조 검출 property 테스트 통과, cond-v2 전 케이스 변환 동일, 컴파일 ≤300ms.
5. **지표**: ≥100종, 참조 벡터 대조 통과, 증분=일괄 동일성.
6. **백테스트 현실성**: 슬리피지·수수료 티어·지연·부분체결·주문유형·펀딩 모델 계약 테스트, 1개월 M1 즉시 백테스트 ≤5s, 딥 백테스트 재개 가능.
7. **실행**: OMS 상태기계가 실제 제출 경로에 배선, 부분체결·취소·정정·재시작 복구·3-way 대사 통합 테스트, pre-trade 지연 CI 단언(R-57).
8. **데이터**: instrument_id 키 조회 p95 200ms(5k봉), 커버리지 밖 요청 fail-closed, 거래소 2곳 SPI 계약 테스트.
9. **차트**: 자체 엔진에서 캔들·지표 오버레이·드로잉 저장/복원(교차 테넌트 404), 빌드·vitest 통과.
10. **운영**: 로컬 CI 녹색, Guard veto 0, INVARIANTS I-01~I-11 위반 0, RED_TEAM_FINDINGS 미해결 P0 0.

## Consequences
- MVP-1 잔여 167 리프. 최근 24시간 실측 처리량(구현 218·QA 121·리뷰 159건, 한도 일시정지 6.4h 포함) 기준
  구현 약 2일, 종료 기준 증빙(패리티·E2E·성능) 약 1일 — **약 3일**.
- post-MVP 41 리프(MP·SIG·CH 고급·DC 계층·R 청산/알림·L4 알고)는 MVP-1 종료 기준 통과 전에는 배정하지 않는다.
- 이 ADR이 PM_CYCLE_PROMPT의 배정 범위를 정의한다. 범위 밖 리프 생성은 PM 결함으로 간주한다.
