# ADR-2026-11-11-A: ruff format 일괄 정리와 CI 게이트

- 상태: 승인 (소유자 채팅 승인 2026-11-11, "권장하는대로 모두 승인")
- 관련: ADR-2026-09-09-D (광범위 리팩터 커밋은 ADR 참조 필요)

## 맥락
CI에는 `ruff check`(린트)만 있고 `ruff format`은 강제되지 않아 tests 345개, src 772개, scripts 29개 파일이
어긋나 있었다. 워커 훅(`format_on_edit.py`)이 최근 변경분의 96%를 이미 포맷하고 있어 게이트화가 현실적이었다.

## 결정
1. 전체를 `ruff format`으로 한 번에 정리한다(커밋 3cac9e272 tests, 1f9eb9e9d src·scripts, 160602569 FROZEN_PAPER_ONLY 38개).
   동작 변경은 없다: 구문 트리를 파일마다 비교해 독스트링 공백 외 차이가 없음을 확인했다.
2. `scripts/check_format.py`를 게이트로 둔다(엔진 `ci_recheck`의 `format` 단계, 워커 push 훅). 위반 0건이라 래칫이 아니라 곧바로 게이트.
3. 제외는 KIS 생성기 출력(`src/exchanges/kis/generated`)뿐이다: 재생성 결과와 바이트 비교하는 테스트가 있다.
4. FROZEN_PAPER_ONLY 구역의 포맷-only 정리는 소유자의 명시 승인으로 수행했고 기록은 task-23483에 있다. 승인 범위는 포맷만이다.

## 일괄 포맷의 알려진 함정
- 줄이 갈라져 `# noqa`가 엉뚱한 줄에 남아 린트 신규 오류(F811, S107)가 생긴다 -> 해당 줄로 옮긴다.
- 줄 수가 늘어 500줄 ratchet을 넘는다 -> 한도를 올리지 않고 독스트링 정리나 테스트 분할로 해소한다.
- 생성기 출력은 포맷하지 않는다.

## 결과
광범위 리팩터 게이트(`refactor_wide`)는 커밋 메시지의 ADR 참조를 요구한다. 1f9eb9e9d는 참조 없이 푸시되어 full CI에서
경고(warn 모드)가 났다. 이 ADR이 그 참조다. 이후 같은 성격의 커밋은 이 ADR을 인용한다.
