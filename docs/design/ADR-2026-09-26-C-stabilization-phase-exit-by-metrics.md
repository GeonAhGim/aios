# ADR-2026-09-26-C: MVP-1 안정화 단계 — 리프 수가 아니라 지표로 종결한다

## Status
Accepted (2026-09-26, Chief Architect). 사용자 승인("CI 녹색은 2~3일로 줄이고 모두 승인").

## Context (실측 2026-09-26)
- MVP-1 명세 리프 493개 중 미완 7개(실제 미구현 2: FA-24·IND-2g 대조, 나머지 5개는 ID 태깅 이전에 구현됨).
- done 리프의 깊이 등급: D2 123 · D3 105 · D? 225(47%) — 절반은 검증 깊이를 모른다.
- 24h 발행 리프 824 중 자기조치(health/ci/rule-gap/Fix QA) 534(65%), 구현 149(18%).
- tier S 주문 경로에서 리뷰가 잡은 치명 결함 3건(멱등키 미전송·심볼 미변환·수량 검증 누락)은 CI가 아니라 사람 수준 리뷰에서만 드러났다.
- 결론: "구현 완료"는 리프 수 완료이지 동작 완료가 아니며, 정정 구간이 구현 구간만큼 길 수 있다.

## Decision
1. **안정화 단계 진입**: 로컬 레인은 새 MVP-1 명세 리프를 발행하지 않는다(남은 3건 task-2681·7924/7925·FA-24만 마무리). ADR-2026-09-26-A의 MVP-2 클라우드 선착수는 그 ADR의 조건(main 녹색 시에만 머지) 그대로 유지.
2. **종결 지표(전부 충족 시 MVP-1 종결)**: (a) GitHub Quality Gate main + 로컬 commit/full CI **3일 연속 녹색**, (b) 재오픈 0(7일 창), (c) 24h 발행 중 자기조치 비율 ≤10%(대시보드 상태 요약), (d) 사용자 여정 J1~J3 e2e 녹색(closeout_check 12항), (e) D? 리프 0 — 깊이 미확정 리프는 QA 등급 판정 후 D2 이상만 done으로 인정(안전축 D3).
3. **도메인별 적대적 감사 리프(6종, 순서 고정)**: ① 주문 경로(OMS→거래소 어댑터 4종→원장, task-7978) ② 원장·회계(이중기입·WORM·백필) ③ 리스크·서킷브레이커·킬스위치 ④ 인증·권한·MFA·RLS ⑤ 데이터 수집·재생(replay·point-in-time) ⑥ 컴플라이언스·승인 워크플로. 감사 리프는 코드를 고치지 않고 `docs/audits/AUDIT_<date>_<domain>.md`에 발견(심각도·파일:줄·재현·조치)을 남긴다. 발견마다 정정 리프를 CTO/PM이 발행하고, 같은 도메인에서 **발견 0건이 두 번 연속**이면 그 도메인 통과.
4. **감사·정정의 우선순위**: 정정 리프는 P0, 감사 리프는 P0, D? 판정은 로컬 QA 레인(P2). 자기조치 리프(ci_red 등)는 계속 P0이되 그 비율 자체가 종결 지표라 엔진 규칙 결함으로 늘어나면 규칙을 먼저 고친다.
5. **기간은 정하지 않는다** — 위 지표가 끝을 정한다. 기준선·게이트·임계값 완화로 지표를 맞추는 것은 금지(DECISION_GUIDELINES B-2).

## Consequences
- PM_CYCLE_PROMPT §B에 -2항(안정화 우선)을 추가한다. 대시보드 상태 요약의 자기조치 비율과 CI 연속 녹색 일수가 종결 진행도다.
- 되돌림: 이 ADR Superseded + PM §B -2항 제거.
