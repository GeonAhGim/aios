# ADR-2026-09-05-A: 지표·전략작성·백테스트의 오픈소스 기반 대규모 확장과 AI 연구·전략 생성 계층

## Status
Accepted (2026-09-05, Chief Architect). 사용자 지시: "차트/지표·전략작성·백테스트를 더 높은 수준으로. TradingView는 수천 지표 —
오픈소스·설치형 모듈로 고도화/확장. 시장을 분석하고 전략을 생성하는 MCP 또는 클라우드형/로컬형 자가발전·학습 AI를 붙여 쓸 수 있어야 한다."

## Context
- ADR-B/명세(IND 100종, DSL, BT 현실성)는 T3 진입선이다. TradingView의 "수천 지표"는 내장 ~100 + 커뮤니티 스크립트 수만 개다.
  같은 규모는 **(1) 오픈소스 지표 라이브러리를 어댑터로 흡수**하고 **(2) 사용자·AI가 AIOS Script로 만든 지표가 마켓에 쌓이는 구조**로만 도달한다.
- 백테스트는 이벤트 구동 엔진(BT-1~12) 하나로는 파라미터 탐색·대규모 유니버스가 느리다. 벡터화 엔진(수천 조합/초)이 별도로 필요하다.
- brainstorm 연구가 도출한 Strategy Factory·Agent Gateway plane(ADR-C에서 "후속")을 지금 착수한다. 단, 연구가 6개 시스템에서 확인한
  안티패턴(I-07 "게이트가 프롬프트에만 존재")을 그대로 반복하지 않는 것이 이 ADR의 핵심 제약이다.

## Decision
### D1. 지표는 3층으로 확장한다 — 코어 100(IND-1~7) + OSS 어댑터 ~300 + 스크립트/마켓 무제한
- **OSS 어댑터 층**: TA-Lib(BSD-3, ~160종), pandas-ta(MIT, ~130종), `ta`(MIT) 등을 **레지스트리 어댑터**로 흡수한다. 각 지표는 코어와
  같은 스펙(입력·파라미터 범위·출력·lookback·버전·참조 벡터)으로 등록되고, 증분=일괄 동일성 계약을 통과해야 노출된다. 라이선스는
  CH-0 방식(원문 확인)으로 리프에서 확정하며 GPL/LGPL 계열(backtrader, tulip, NautilusTrader)은 코드 차용·링크 금지, 패턴만.
- **스크립트 층**: AIOS Script 사용자 지표(IND-8)와 마켓 리스팅(MP)이 "수천"의 실체다. **Pine Script 가져오기 변환기(부분)**를 추가해
  TradingView 커뮤니티 자산을 사용자가 직접 이식할 수 있게 한다(호환 실행기 아님 — 변환 후 AIOS Script로 컴파일·검증, 미지원 구문은 명시 거부).
- 차트는 지표 플러그인 API(오버레이·페인·스타일)와 "스크립트 지표 즉시 미리보기"로 이 3층을 그대로 소비한다.

### D2. 백테스트는 이벤트 구동 + 벡터화의 2엔진, 같은 데이터·같은 체결 모델 계약
- **벡터화 엔진**(numpy/numba, vectorbt OSS(Apache-2.0)의 설계를 참조하되 코드는 자체): 파라미터 그리드·유니버스 스윕·Monte Carlo·
  워크포워드 대량 실행. 체결 현실성 모델(BT-2~6)을 벡터 형태로 동일 구현하고, 이벤트 엔진과의 **결과 동등성 테스트**(같은 단일 조합 → 동일 체결)를 계약으로 둔다.
- 결과는 실험 원장(Experiment Ledger)에 재현 키와 함께 불변 기록된다. 이 원장이 AI 자가개선 루프(D4)의 유일한 학습 입력이다.

### D3. AI 연구·전략 생성 계층은 "제안자"이지 "결정자"가 아니다 (Strategy Factory + Agent Gateway)
- **Agent Gateway**: AIOS가 **MCP 서버(얇은 프록시, I-08)**를 제공한다. 도구는 read(시장데이터·지표·커버리지)·research(백테스트 실행·실험 조회)·
  propose(전략 초안 제출)·paper(PAPER 실행 요청)로 닫힌 스코프 enum이며, **인간 세션과 분리된 서버측 revoke 가능 토큰**(I-06)으로만 접근한다.
  자금 이동·LIVE·리스크 정책 변경 capability는 게이트웨이에 존재하지 않는다. 2단계 확인은 서버측 1회성 토큰(I-11).
- **모델 공급자 추상화**: Claude API(클라우드)·로컬 LLM(Ollama/vLLM 등 OpenAI 호환 엔드포인트)·외부 에이전트(MCP 클라이언트)를 같은
  `ModelProvider` 포트로. 사용자가 테넌트별로 공급자·키·비용 상한을 설정한다. 어떤 공급자든 산출물 형식은 동일하다.
- **산출물 형식은 AIOS Script + 가설 + 데이터 범위**로 고정(스키마 강제 생성). LLM의 자유 텍스트 코드·자유 JSON은 받지 않는다.
- **결정론 게이트 필수 통과**: 컴파일(DSL) → 검증 파이프라인(DSR/PBO/워크포워드, I-07 실제 FAIL) → 리스크 게이트(Master Authority) →
  PAPER. 어느 단계도 프롬프트로 대체되지 않으며, `tests/adversarial/risk/test_no_llm_in_risk_path`(R-56)가 "리스크 경로에 LLM 없음"을 증명한다.

### D4. "자가발전·학습"은 실험 원장 위의 폐루프이며, ML 신호 모델은 지표의 한 종류로 취급한다
- **폐루프**: 제안 → 검증 → PAPER 실적(검증된 사용) → 실험 원장 → 다음 제안의 컨텍스트. 에이전트는 자기 과거 실험을 조회해 개선하되,
  승격 기준은 사람이 정한 정책(검증 정책 번들)이고 에이전트는 그 정책을 읽을 수만 있다.
- **ML 신호 모델**(LightGBM/torch 등): 피처 스토어·학습 잡·모델 레지스트리(버전·해시·학습 데이터 계보)·드리프트 모니터를 갖추고,
  등록된 모델은 `ml.*` 지표로 AIOS Script에서 호출된다. 백테스트에서는 **학습 시점 이후 데이터만 사용**하도록 point-in-time 규칙을
  강제한다(룩어헤드 차단은 DSL-5의 정적 검출과 별개로 데이터 계보 수준에서 한 번 더).
- 로컬 학습(사용자 GPU)과 클라우드 학습을 같은 잡 인터페이스로 두고, 모델 아티팩트는 마켓에서 "보호 소스"로 판매 가능하다(MP 규칙 그대로).

### D5. 경계
- 실행 엔진·리스크 게이트·원장은 변경하지 않는다. AI 계층은 전부 새 컨텍스트(`src/foundation/ai/**`, `src/foundation/experiments/**`,
  `src/foundation/ml/**`, `src/api/mcp/**`)에 얹힌다.
- 외부 데이터·뉴스·소셜 피드 연결은 이 ADR 범위 밖(데이터 벤더 결정과 함께 사람 결정).

## Consequences
- 명세 `L4_analytics_authoring_backtest_marketplace_v1.0.md`에 확장 리프(IND-9~14, BT-14~18, DSL-14~16, CH-11~13)를, 새 명세
  `L4_ai_research_strategy_factory_v1.0.md`에 AI-1~22(게이트웨이·공급자·연구 에이전트·전략 생성·실험 원장·ML 신호)를 추가한다.
- MVP-1은 약 +50 리프. 순서: 기존 축 유지 → IND OSS 어댑터·BT 벡터화(DSL·BT 코어 직후) → AI(DSL-12·BT-10·MP-1 이후; 게이트웨이 먼저).
- 라이선스 검증 리프(IND-9, BT-14, AI-3)가 통과하기 전에는 어떤 OSS도 반입하지 않는다.

## Rejected
- Pine Script 호환 실행기(ADR-B 유지). 변환기는 "가져오기 도구"이며 실행 의미론은 AIOS Script다.
- LLM이 주문·리스크·승격을 직접 결정하는 구조(brainstorm이 6개 시스템에서 확인한 실패 양식).
- GPL/LGPL 백테스트·지표 코드 차용.
