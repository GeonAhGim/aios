# ADR-2026-09-06-J: 무인 운영 모델 — 되돌릴 수 있는 것은 자동으로, 아닌 것만 사람에게

## Status
Accepted (2026-09-06, Chief Architect). 사용자 지시: "기본적으로 내가 없어도 클로드 코드가 알아서
100% 완벽하게 프로젝트를 성공시킬 수 있어야 한다."

## Context
함대는 이미 스스로 돈다 — 오케스트레이터가 워커를 띄우고, PM이 다음 리프를 만들고, 로컬 CI가 커밋마다
게이트를 돌린다. 그런데 2026-09-06 하루를 되짚으면 **멈춘 것은 전부 조용히 멈췄고, 사람이 물어봐야 발견됐다**:
게이트 미배선(P0 8건), 보류 132건 영구 정지, 품질 검사 5종 미호출, 낡은 프로세스 2회, 디스크 3.2GB.

구조적으로 보면 **감지는 자동인데 조치가 수동**이었다. 디스크가 찼다고 알려주지만 비우지 않았고,
프로세스가 죽었다고 알려주지만 살리지 않았다. Chief Architect 세션이 붙어 있는 동안만 굴러갔다.

## 핵심 원칙
**되돌릴 수 있는 것은 자동으로 하고, 되돌릴 수 없는 것만 사람에게 남긴다.**
프로세스 기동, 캐시 삭제, 상태 되돌리기는 되돌릴 수 있다.
코드 수정·커밋·revert·스키마 변경·돈이 움직이는 결정은 되돌릴 수 없거나 워커·사람의 몫이다.

## Decision

### D1. 4겹 자율 루프 (전부 토큰 0)
| 층 | 주체 | 주기 | 역할 |
|---|---|---|---|
| 실행 | `orchestrator.py` | 20초 | 워커 배정·재시도·QA/Review 체인·PM 트리거 |
| 검증 | `local_ci.py` | 커밋마다 | 11개 게이트 + 프런트 린트·빌드·테스트 |
| 회귀 방지 | `check_audit_regressions.py` | CI + 5분 | 감사 발견 8종을 단언으로 고정(래칫) |
| 자가 치유 | `healthcheck.py` | 5분 | 12종 점검 + **되돌릴 수 있는 자동 조치** |

### D2. 자동 조치 대상 (되돌릴 수 있는 것만)
- 죽은 상주 프로세스 기동
- 유예를 넘긴 낡은 프로세스 강제 재시작
- 디스크 바닥 시 캐시·오래된 임시파일 정리(저장소·워크트리·DB는 건드리지 않는다)
- 게이트가 끝났는데 안 풀린 보류 해제
- 실행 중 표시인데 프로세스가 없는 태스크 재배정

**폭주 방지**: 같은 조치가 1시간에 3회를 넘으면 손을 떼고 심각도를 올린다.
무한 재시도가 문제를 감추는 것이 가장 나쁜 실패다.

### D3. 상주 스크립트는 스스로 갈아탄다
`selfreload.reexec_if_changed`가 폴링 경계에서만 재시작한다(작업 중간이 아니다).
공용 헬퍼 변경도 감시한다. 코드를 고치고 재시작을 잊는 사고가 하루에 두 번 났다.

### D4. 굶주림을 시간으로 잡는다
결정 대기·차단 태스크가 4시간을 넘으면 high로 올린다. 함대가 조용히 굶는 것이 정지의 주 경로다.
배정 가능한 일이 0인데 보류·결정대기가 남아 있는 상태도 별도로 잡는다.

### D5. 사람만 할 수 있는 일을 한 곳에 모아 항상 보이게 한다
`pm/human_blocked.json`에 등록하고 대시보드에 상시 표시한다. `blocking` 플래그로
"진행을 실제로 막는 것"과 "나중에 필요한 것"을 구분한다. 조용히 기다리는 상태를 만들지 않는다.

### D6. 자동화하지 않는 것 — 정직하게 못 박는다
| 항목 | 이유 |
|---|---|
| 계정 발급·API 키 | 본인 확인이 필요하다 |
| 유료 계약·결제 | 법적 주체가 사람이다 |
| 실자금 개통 | 돈이 실제로 움직인다. ADR-2026-08-29-E 하드가드 유지 |
| 실시간 시세 재배포 계약 | 법적 문제이지 기술 문제가 아니다 |
| revert·스키마 파괴 변경 | 되돌리기 어렵다. 워커의 수정 태스크로 처리한다 |

**따라서 "100% 무인"은 이 여섯 항목에 대해서는 성립하지 않는다.** 대신 이것들이
(1) 진행을 막지 않도록 우회 경로를 두고, (2) 막는 경우 즉시 보이게 한다. 조용히 정지하지 않는 것이 목표다.

## Consequences
- Chief Architect 세션이 없어도 함대가 굴러가고, 스스로 못 푸는 것만 대시보드에 남는다.
- 감사는 이제 이벤트가 아니라 상시 게이트다. 같은 결함이 다시 들어오면 CI가 막는다.
- 자동 조치가 실패를 감출 위험은 3회 상한과 조치 이력(`remediation_attempts.json`)으로 통제한다.

## Rejected
- **자동 revert**: 되돌리기가 또 다른 파괴가 될 수 있다. 리뷰어 veto는 수정 태스크로 전환한다.
- **자동 코드 수정으로 CI 적색 해소**: 워커가 할 일이다. 자가 치유 층이 코드를 만지면 책임 경계가 무너진다.
- **무제한 재시도**: 문제를 감춘다. 상한을 두고 손을 뗀다.
- **"사람 개입 0"을 목표로 삼기**: 계정·계약·실자금은 원리적으로 자동화 대상이 아니다.
  달성 불가능한 목표를 세우면 실제로 막힌 지점이 안 보이게 된다.
