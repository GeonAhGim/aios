# Idea Bank Policy

이 저장소는 AIOS의 아이디어 보존과 검토를 위한 저장소다.

- 아이디어는 구현 명령이 아니다.
- `ACCEPTED` 상태도 실제 시스템 반영 전에는 AIOS ADR/Spec 승격이 필요하다.
- 금융규제·AML·세무·회계 관련 내용은 실제 상용화 전 관할 전문가 검토를 거친다.
- AIOS 안전 invariant를 약화시키는 아이디어는 채택할 수 없다.
- 사용자/Creator/외부 Agent에게 LIVE authority를 부여하는 모든 아이디어는 별도 security review 대상이다.
