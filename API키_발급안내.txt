========================================================================
AIOS 무료 데이터 API 키 발급 안내
작성 2026-09-06 / 근거 ADR-2026-09-06-A, ADR-2026-09-06-H
========================================================================

전부 무료입니다. 결제 정보 입력이 필요한 곳은 하나도 없습니다.
여섯 곳 중 다섯 곳이 키 발급이고, 미국 SEC 한 곳은 키가 없는 대신
헤더 설정이 필요합니다.

받은 키는 맨 아래 "키 넣는 곳" 절차대로 .env 파일에 넣으시면 됩니다.
.env는 git에 올라가지 않도록 이미 제외돼 있습니다.

메뉴 이름과 일일 한도는 사이트 개편에 따라 바뀔 수 있습니다.
아래와 다르면 사이트 안내를 따르시면 됩니다.


------------------------------------------------------------------------
1) OpenDART  (금융감독원 전자공시)  ***가장 중요***
------------------------------------------------------------------------
용도  : 국내 기업 공시. 액면분할, 합병, 현금배당 같은 기업행위의
        1차 원본입니다. 유료 데이터 벤더들이 재판매하는 바로 그 원본이라,
        여기서 직접 받는 편이 정확도와 정정 추적 모두 낫습니다.

주소  : https://opendart.fss.or.kr

절차  : 1. 우측 상단 회원가입
        2. 상단 메뉴 "인증키 신청/관리" → "인증키 신청"
        3. 이름, 이메일, 사용 목적 입력
        4. 입력한 이메일로 온 인증 메일에서 링크 클릭
        5. "인증키 신청/관리"에서 발급된 키 확인

소요  : 이메일 인증 직후 바로 발급
키형태: 영문 소문자와 숫자 40자리
한도  : 계정당 하루 20,000건 수준
.env  : OPENDART_API_KEY

상용화: 공시 원문은 공공데이터라 상업적 이용이 가능합니다.
        다만 가공해서 배포할 때 출처 표기 조건이 있으니
        서비스 오픈 전에 이용약관을 한 번 확인하시면 됩니다.


------------------------------------------------------------------------
2) 한국은행 ECOS  (경제통계시스템)
------------------------------------------------------------------------
용도  : 국내 거시지표와 환율. 특히 원화 환율을 지금의 임시 중간값 대신
        기관 고시값으로 바꾸는 데 씁니다.

주소  : https://ecos.bok.or.kr

절차  : 1. 회원가입
        2. 상단 "오픈API" → "인증키 신청"
        3. 활용 용도 기재 후 신청
        4. 이메일로 인증키 수신

소요  : 즉시에서 1영업일
한도  : 하루 10,000건 수준
.env  : ECOS_API_KEY

상용화: 상업적 이용 가능, 출처 표기 조건입니다.


------------------------------------------------------------------------
3) KOSIS  (국가통계포털 공유서비스)
------------------------------------------------------------------------
용도  : 국내 통계 전반. 거시 분석과 리서치 데이터의 보조 소스입니다.

주소  : https://kosis.kr/openapi/

절차  : 1. 회원가입
        2. "활용신청" 메뉴에서 서비스명과 활용 목적 기재
        3. 승인 후 "사용자등록번호"가 발급됨. 이것이 인증키입니다

소요  : 즉시에서 1영업일
.env  : KOSIS_API_KEY

참고  : 신청서에 서비스명을 적는 칸이 있습니다. "AIOS" 로 적으시면 됩니다.


------------------------------------------------------------------------
4) FRED  (미국 세인트루이스 연방준비은행)
------------------------------------------------------------------------
용도  : 미국 거시지표. 금리, 물가, 고용 등 해외 매크로의 표준 소스입니다.

주소  : https://fred.stlouisfed.org/docs/api/api_key.html

절차  : 1. 위 주소에서 계정 생성 (이메일만 있으면 됩니다)
        2. 로그인 후 "Request API Key"
        3. 사용 목적을 영어 한 줄로 기재 (예: Personal trading research)
        4. 즉시 발급

소요  : 즉시
키형태: 영문 소문자와 숫자 32자리
.env  : FRED_API_KEY

상용화: 상업적 이용 허용입니다. 출처 표기만 하면 됩니다.


------------------------------------------------------------------------
5) SEC EDGAR  (미국 증권거래위원회)  ※ 키 발급이 없습니다
------------------------------------------------------------------------
용도  : 미국 기업 공시.

주소  : https://www.sec.gov/os/accessing-edgar-data

절차  : 가입도 키 발급도 없습니다. 대신 요청 헤더에 신원을 밝혀야 하고,
        밝히지 않으면 차단됩니다. 이 부분을 놓치면 잘 되다가 갑자기
        403으로 막히므로 처음부터 넣어둡니다.

형식  : "회사명 또는 서비스명" 다음에 한 칸 띄고 연락 가능한 이메일
        예시 → AIOS guchosun@gmail.com

제한  : 초당 10회
.env  : SEC_EDGAR_USER_AGENT
        위 예시 문자열을 그대로 값으로 넣으시면 됩니다.


------------------------------------------------------------------------
6) 공공데이터포털  (선택 사항, 국내 시세용)
------------------------------------------------------------------------
용도  : 금융위원회 주식시세정보 등 국내 시세 데이터.
        1차 MVP에는 필수가 아니지만 국내 종목을 다룰 때 편합니다.

주소  : https://www.data.go.kr

절차  : 1. 회원가입
        2. 검색창에 "금융위원회_주식시세정보" 검색
        3. 해당 API에서 "활용신청" 클릭, 활용 목적 기재
        4. 자동승인이면 즉시, 아니면 1~2영업일
        5. "마이페이지 → 개발계정"에서 인증키 확인

주의  : 인증키가 Encoding 값과 Decoding 값 두 개로 나옵니다.
        Decoding 값을 쓰시면 됩니다.

한도  : 개발계정 하루 10,000건. 운영계정으로 전환 신청하면 상향됩니다.
.env  : DATAGOKR_SERVICE_KEY

상용화: 국내 실시간 시세를 상용 서비스 화면에 띄우려면 이 키와 별개로
        거래소 또는 정보사업자와의 정보이용계약이 필요합니다.
        이건 데이터를 어떻게 구했느냐와 무관한 법적 요건입니다.
        서비스 공개 전에 별도로 확인이 필요한 항목입니다.


========================================================================
키 넣는 곳
========================================================================

파일  : C:\aios\aios\.env
        (없으면 같은 폴더의 .env.example 을 복사해서 .env 로 이름 변경)

편집  : 메모장으로 열어서 아래 여섯 줄을 맨 아래에 붙여넣고
        오른쪽에 받은 값을 채우시면 됩니다. 따옴표는 넣지 않습니다.

OPENDART_API_KEY=
ECOS_API_KEY=
KOSIS_API_KEY=
FRED_API_KEY=
SEC_EDGAR_USER_AGENT=AIOS guchosun@gmail.com
DATAGOKR_SERVICE_KEY=

주의  : .env 파일은 git에 올라가지 않도록 이미 제외돼 있습니다.
        키를 채팅창이나 문서에 붙여넣지 마시고 이 파일에만 넣어 주세요.
        여섯 개 중 일부만 받으셔도 됩니다. 받은 것부터 순서대로 쓰입니다.

우선순위: 시간이 없으시면 1번 OpenDART 와 4번 FRED 두 개만 먼저 받으셔도
        상당 부분이 열립니다. 특히 1번은 기업행위 데이터의 원본이라
        유료 계약 하나를 통째로 대체합니다.


========================================================================
나중에 상용화할 때 확인할 것  (지금은 하실 일 없습니다)
========================================================================

- 위 여섯 곳은 대부분 상업적 이용이 가능하지만, 출처 표기 조건이 붙습니다.
  서비스 하단에 데이터 출처를 표기하는 것으로 충족됩니다.

- 계정 등급을 개인에서 기업으로 올려야 하는 경우가 생기면,
  AIOS 쪽은 코드를 고치지 않습니다. 소스별 계약 정보를 행 하나로
  관리하도록 설계해 두었으므로 등급과 키만 교체하면 됩니다.
  (근거: ADR-2026-09-06-H)

- 진짜로 계약이 필요해지는 지점은 셋뿐입니다.
  첫째, 국내외 실시간 시세를 상용 화면에 띄울 때의 재배포 권리.
  둘째, 미국 주식과 옵션의 체결 단위 데이터.
  셋째, 공매도 차입 가능 수량. 이건 데이터 구매가 아니라 증권사 계좌입니다.
  나머지는 직접 구축으로 대체하도록 결정해 두었습니다.
