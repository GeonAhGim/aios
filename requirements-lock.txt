# requirements-lock.txt -- exact, reproducible venv for this repo (task-3577).
#
# Problem this solves: rebuilding the venv from pyproject.toml alone lets pip
# pick whatever the newest matching release is on the day of the install, and
# that has repeatedly produced a different, broken environment than the one
# CI/other machines are actually running on -- e.g. TA-Lib 0.8.0/0.6.8 (instead
# of 0.7.1) breaking tests/unit/core/indicators/test_generate_specs.py's
# expected indicator count, pytest-timeout/tzdata missing outright, and a
# pydantic point release changing market_data JSON-schema snapshots.
#
# Regenerate (only when you intend to move the pinned floor -- see
# docs/DEPENDENCIES.md):
#   py -3.10 -m venv <scratch-venv>
#   <scratch-venv>/Scripts/python -m pip install -e "C:\aios\aios[dev,test]"
#   <scratch-venv>/Scripts/python -m pip freeze | grep -v '^-e ' > requirements-lock.txt
# Then reinstall the real venv from the lock file (`pip install -r
# requirements-lock.txt`) and run `pytest tests/unit -q` before committing the
# refreshed file.
#
# Install: pip install -r requirements-lock.txt && pip install -e . --no-deps
